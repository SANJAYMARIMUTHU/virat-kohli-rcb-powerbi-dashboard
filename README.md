# Virat Kohli RCB IPL Performance Dashboard

## Overview

Interactive Power BI dashboard analyzing Virat Kohli's IPL performance for Royal Challengers Bengaluru (RCB).

## Tools Used

* Power BI
* Python
* Pandas
* DAX

## Features

* Total Runs Analysis
* Runs by Season
* Runs vs Opponent
* Boundary Analysis
* Dismissal Analysis
* Scoring Pattern by Over
* Interactive Season Filter
